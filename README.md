# Event Management System

## Project Overview
A console-based application for managing events and participant registrations, built with Python.

## Features
- Create, view, search, update, and delete events
- Register and remove participants
- View registered participants
- Calculate event ticket revenue
- Validate user inputs and handle common errors

## Technologies
- Python
- Object-Oriented Programming (OOP)
- Built-in Python features: lists, loops, conditional statements, and exception handling
